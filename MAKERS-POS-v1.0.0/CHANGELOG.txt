Version 1.0.0 (Official Release Candidate) — 2026-09-29
--------------------------------------------------------------------------------
Initial Major Production Release of MAKERS POS Desktop Suite.

Highlights of completed, verified, and hardened capabilities:

[Desktop Experience & Fullscreen]
- Native Tauri 2.x + Rust desktop execution with automatic maximized startup.
- Clean launch without console/terminal windows or developer dependencies.
- Embedded SQLite transactional database with WAL mode and foreign key enforcement.
- Automated migration engine with 11 sequential schema versions and idempotency.

[Barcode Labels & Sticker Generator]
- Dedicated Barcode Label generator supporting EAN-13, Code128, and custom SKUs.
- Multi-size presets: 50x25mm (Standard), 40x30mm, 60x40mm, 38x25mm, and custom.
- Real-time 1:1 single label card preview and multi-label quantity grid preview.
- Dedicated vector printing engine with isolated print stylesheet.

[MAKERS Web Catalog Integration]
- 1-Click Search & Importer on Products page header for instant catalog lookup.
- 4-Stage duplicate detection (Website ID, Website SKU, Barcode, Internal SKU).
- Duplicate Add-Stock workflow to adjust existing stock without creating duplicate records.
- CORS-bypassing native Rust HTTP client with 15-second timeout and custom user-agent.

[Thermal Receipt Engine & Redesign]
- High-contrast, structured receipt redesign with bold typography and clear borders.
- Dedicated templates for Sales Invoices, Return Notes, and Expense Vouchers.
- Dynamic 80mm and 58mm paper width support with cutter safety bottom clearance.
- Item name wrapping for mixed Arabic and English without price overlapping.
- Detailed payment breakdowns for single and split payments (Cash, Card, Credit).

[POS Cashier, Inventory & Finance]
- High-velocity cashier register with instant search and barcode scanner auto-add.
- Multi-location stock management, low-stock reorder thresholds, and immutable movement logging.
- Supplier purchasing, Purchase Orders, and supplier credit balance tracking.
- Customer profiles, credit limits, and balance ledger tracking.
- Resellable (restocked) vs Damaged (scrapped) returns processing.
- Cash drawer shift lifecycle: Opening balance, Pay-ins, Pay-outs, and Closing reconciliation.
- Read-only real-time reports: Sales overview, Gross Profit, Returns, Expenses, Purchases.

[Quality & Reliability]
- 560 automated verification tests with 100% pass rate across 17 regression suites.
- Transactional backup creation with automatic retention rotation.
- Pre-restore emergency snapshot mechanism preventing accidental data loss during restore.
