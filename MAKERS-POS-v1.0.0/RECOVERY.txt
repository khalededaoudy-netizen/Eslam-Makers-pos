================================================================================
MAKERS POS v1.0.0 — BACKUP & DISASTER RECOVERY MANUAL
================================================================================

1. BACKUP ARCHITECTURE
----------------------
MAKERS POS includes an integrated SQLite backup engine designed to protect
store records against hardware failure, operator mistakes, and system crashes.

Default Storage Locations:
- Active Database:
  %APPDATA%\com.makers.pos\makers_pos.db
- Backups Directory:
  %APPDATA%\com.makers.pos\backups\
- Pre-Restore Emergency Snapshots:
  %APPDATA%\com.makers.pos\backups\emergency\


2. MANUAL BACKUP PROCEDURE
--------------------------
1. Log in to MAKERS POS as an Administrator.
2. Navigate to "Settings" -> "Database & Backups".
3. Click "Create Backup Now".
4. The system locks the database using SQLite VACUUM INTO, generating a clean,
   transactionally consistent snapshot with a timestamped filename:
   makers_pos_backup_YYYYMMDD_HHMMSS.db
5. We strongly recommend copying backup files to an external USB drive or off-site cloud storage daily.


3. DATABASE RESTORATION PROCEDURE
---------------------------------
1. Navigate to "Settings" -> "Database & Backups".
2. Under "Available Backups", select the desired backup snapshot.
3. Click "Restore Database".
4. Type the confirmation phrase as prompted.
5. The system automatically executes a 3-step safe restore protocol:
   Step 1: Creates an automatic emergency snapshot of the current database state.
   Step 2: Atomically swaps the active database file with the selected backup.
   Step 3: Executes PRAGMA integrity_check and PRAGMA foreign_key_check.
6. The application reloads with restored historical data intact.


4. MANUAL DISASTER RECOVERY (APP CANNOT LAUNCH)
-----------------------------------------------
If Windows crashes or files are corrupted and the application cannot open:

1. Close any running instances of "MAKERS POS.exe".
2. Open Windows File Explorer and navigate to:
   %APPDATA%\com.makers.pos\
3. Rename corrupted file "makers_pos.db" to "makers_pos_corrupted.bak".
4. Open the "backups" subfolder and select the most recent valid backup file.
5. Copy that backup file into %APPDATA%\com.makers.pos\ and rename it to:
   makers_pos.db
6. Relaunch "MAKERS POS.exe".


5. DATABASE INTEGRITY INVARIANTS
--------------------------------
The database is guaranteed to maintain:
- Foreign key constraints enabled on all tables
- Zero orphan sale items, return items, or payment records
- Exact equality between sales ledger and cash register drawer movements
- Non-negative stock constraints for standard inventory management
