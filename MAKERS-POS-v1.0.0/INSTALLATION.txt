================================================================================
MAKERS POS v1.0.0 — INSTALLATION & DEPLOYMENT GUIDE
================================================================================

1. PORTABLE / DIRECT DEPLOYMENT
-------------------------------
MAKERS POS is packaged as a standalone, zero-dependency Windows executable.
No installer or runtime setup scripts are mandatory.

Steps:
1. Copy the "MAKERS-POS-v1.0.0" folder to the desired workstation folder:
   Recommended location:
   C:\Program Files\MAKERS POS\
   or
   C:\MAKERS POS\
2. Create a desktop shortcut to "MAKERS POS.exe".
3. Launch "MAKERS POS.exe". The window will open maximized automatically.


2. DATABASE INITIALIZATION BEHAVIOR
-----------------------------------
- The application automatically detects and connects to the SQLite database located at:
  C:\Users\<Current-User>\AppData\Roaming\com.makers.pos\makers_pos.db
- On first launch:
  * Creates the "com.makers.pos" directory if not present.
  * Runs all internal schema migrations idempotently.
  * Seeds foundational reference data (roles, default admin, store settings).
- On subsequent launches:
  * Validates existing database integrity.
  * Preserves 100% of existing products, customers, transactions, and logs.
  * Never overwrites or truncates existing production data.


3. THERMAL PRINTER SETUP (Xprinter XP-80C / Rongta / Epson)
-----------------------------------------------------------
1. Connect printer via USB and power on.
2. Install the manufacturer Windows driver (e.g. "XP-80C Driver" or "POS-80").
3. In Windows "Printers & Scanners", set the printer paper size to "80 x 297 mm" or "80mm Roll".
4. Open MAKERS POS, go to "Settings" -> "Store Settings" -> "Receipt Printing".
5. Choose "80mm" or "58mm" paper width.
6. Print a test receipt from POS or Sales history to verify cut alignment.


4. BARCODE SCANNER SETUP
------------------------
1. Plug scanner USB cable or wireless dongle into the POS station.
2. Verify scanner is in "HID Keyboard Emulation" mode.
3. Test by scanning a barcode into Notepad: the barcode number should appear followed by a newline/Enter.
4. In MAKERS POS, scanning any registered product barcode automatically adds it to the active cart with audio feedback.


5. BARCODE LABEL / STICKER PRINTING
-----------------------------------
1. Navigate to "Barcode Labels" (استيكرات الباركود) in the sidebar.
2. Search and select any product from your catalog.
3. Choose label dimensions (e.g. 50x25mm, 40x30mm, 60x40mm, 38x25mm) and quantity.
4. Preview the scannable vector barcode.
5. Click "Print Labels" to print directly to your label printer.


6. UNINSTALLATION & DATA PRESERVATION
------------------------------------
- To remove the application: Simply delete the application folder or executable.
- Your store database and backup snapshots are kept safe in:
  %APPDATA%\com.makers.pos\
- If you reinstall or upgrade to a newer version in the future, the new version will seamlessly reconnect to your existing database.
